# Charles T. Nzelu — Personal Portfolio

A personal portfolio showcasing frontend development, graphic design, and video editing work.

## Built With

- React
- Vite
- Tailwind CSS
- HTML
- CSS
- JavaScript

## Featured Work

- Real Estate Marketplace
- Car Marketplace
- Graphic Design
- Video Editing

## Local Development

1. Install dependencies:
   npm install
2. Start the dev server:
   npm run dev
3. Build for production:
   npm run build
4. Preview the production build:
   npm run preview

## Project Notes

This portfolio is designed to present Charles T. Nzelu's multidisciplinary creative practice across design, frontend development, and video editing.
